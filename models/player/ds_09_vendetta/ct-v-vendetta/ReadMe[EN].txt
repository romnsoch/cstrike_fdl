1. Installation
____________
Installation is standard. Move the MDL files from the archive to the cstrike/models folder.
MDL files in cstrike/models (models)
WAV files in cstrike/sound (sounds)
TGA files in cstrike/gfx/vgui (pictures for the purchase menu)
SPR files in cstrike/sprites (effects)

The folder cstrike is located in the directory:

NON-STEAM ...\Counter-Strike 1.6\cstrike

STEAM ...\Steam\steamapps\common\Half-Life\cstrike

Note:
If HD mode is not activated, i.e. the quality is poor or blurry. Write in the console gl_max_size 1024 should help.
If you play with the bots, then write the command mp_consistency 0 in the console. ("Server is enforcing file consistency" error)
If all of our recommendations did not help you, then we recommend that you download CS 1.6 clean version from our site. All our skins/models are checked only on our build.
Link to CS 1.6 https://downloading-cs.su
Make copies of the files you are going to replace. If you don't like the skin, you can restore everything without loss.
In the extreme case, you can download our weapons package (standard) and replace or download our original client. Then all the standard models/files will be restored.
You decide which files to install. For example, 
If you liked the skin, but did not like the sound of firing or just sounds, you can simply ignore these files.
